# Project conventions
- Use the shared Icon3D raster pack for dimensional navigation, summary and section icons; keep small field and action icons as Lucide for readability.
- Scope soft-3D surface rules to the app shell and explicitly marked shared primitives; keep authentication and printed invoices independent to avoid altering their layouts.
- Define all new surface colors, gradients and shadows as semantic CSS tokens with dark-mode equivalents so persisted theme settings remain compatible.
